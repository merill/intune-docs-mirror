# Console support - Configuration Manager | Microsoft Learn

*Applies to: Configuration Manager (current branch)*

Configuration Manager supports the installation of the console on the following Windows OS versions:

- **Windows Server 2025**: Standard, Datacenter (*starting in version 2409*)
- **Windows Server 2022**: Standard, Datacenter (*starting in version 2107*)
- **Windows Server 2019**: Standard, Datacenter
- **Windows Server 2016**: Standard, Datacenter
- **Windows 11** (x64): Pro, Enterprise
- **Windows 10** (x86, x64): Pro, Enterprise

For more information about the Configuration Manager console, see the following articles:

- [Install consoles](../../servers/deploy/install/install-consoles)
- [Using the console](../../servers/manage/admin-console)
