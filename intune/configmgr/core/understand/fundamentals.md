# Fundamentals - Configuration Manager | Microsoft Learn

*Applies to: Configuration Manager (current branch)*

If you're new to Configuration Manager current branch, start with the fundamentals. Before you run setup to install your first site, learn about the basic concepts of Configuration Manager. If you're already familiar with System Center 2012 Configuration Manager, then start with [What's changed from System Center 2012 Configuration Manager](../plan-design/changes/what-has-changed-from-configuration-manager-2012).

For information about supported operating systems and supported environments, hardware requirements, and capacity information, see [Supported configurations for Configuration Manager](../plan-design/configs/supported-configurations).
