# Client deployment planning - Configuration Manager | Microsoft Learn

*Applies to: Configuration Manager (current branch)*

The following pages in this section provide information on planning for various client installation methods and the various details of deploying the client to different platforms in your organization:

- [Prerequisites for deploying clients to Windows computers](../prerequisites-for-deploying-clients-to-windows-computers)
- [Planning for client deployment to Mac computers](planning-for-client-deployment-to-mac-computers)
- [Planning for client deployment to Windows Embedded devices](planning-for-client-deployment-to-windows-embedded-devices)
