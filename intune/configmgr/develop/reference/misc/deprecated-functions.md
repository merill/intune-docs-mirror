# Deprecated functions - Configuration Manager | Microsoft Learn

While these functions worked in previous product version, don't use them. They might not be available in future releases of Configuration Manager.

- AMTOperateForCollection method in class SMS\_Collection
- AMTOperateForMachines method in class SMS\_Collection
- SmsCreateAccount
- SmsGrantActAsOSRight
- SmsGrantAdminRight
- SmsGrantDomainAdminRight
- SmsGrantServiceLogonRight
- SmsLsaAccount
- SmsLsaGetTrustedDomains
- SubmitAMTCert method in class SMS\_Site
