# Toolkit reference - Configuration Manager | Microsoft Learn

This reference is part of Microsoft® Deployment Toolkit (MDT) 2013 and provides configuration settings that you can use in the deployment process. Review the MDT 2013 documents [Microsoft Deployment Toolkit Samples Guide](samples-guide) and [Using the Microsoft Deployment Toolkit](use-the-mdt) for help in customizing configuration settings for the deployment environment.

Note

In this document, *Windows* applies to the Windows 8.1, Windows 8, Windows 7, Windows Server® 2012 R2, Windows Server 2012, and Windows Server 2008 R2 operating systems unless otherwise noted. MDT does not support ARM processor-based versions of Windows. Similarly, *MDT* refers to MDT 2013 unless otherwise stated.
