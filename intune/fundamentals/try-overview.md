# Try Microsoft Intune for free - Microsoft Intune | Microsoft Learn

You can evaluate and use Microsoft Intune with a free trial.

In this series of articles, you learn how to evaluate Microsoft Intune by stepping through common tasks, like adding users and groups, enrolling devices, creating policies, and adding apps. You can use a free trial to complete the steps in this series.

To learn more about Intune, see [What is Microsoft Intune?](what-is-intune) and [Benefits of Microsoft Intune training path](/en-us/training/modules/benefits-microsoft-endpoint-manager/).

## Recommended prerequisites

The following list includes recommended prerequisites when setting up Microsoft Intune:

- Use available devices on [supported operating systems](ref-supported-platforms)
- Be familiar with [network endpoints for Microsoft Intune](endpoints)
- Have an [app](../app-management/ref-protected-apps) that you can add to Intune, like a Microsoft 365 app
- Be familiar with [role-based access control (RBAC) in Intune](role-based-access-control/overview)

## Tasks in this series

In these topics, you set up a test environment. Then, you step through common tasks that help you better understand and use Intune.

- [Step 1 - Set up the Microsoft Intune free trial](free-trial-sign-up)
- [Step 2 - Create a user and assign a license](tenant-administration/quickstart-create-user)
- [Step 3 - Create a group](tenant-administration/quickstart-create-group)
- [Step 4 - Set up automatic enrollment](../device-enrollment/windows/quickstart-automatic-mdm)
- [Step 5 - Enroll your Windows device](../device-enrollment/windows/quickstart-first-device)
- [Step 6 - Create a compliance policy](../device-security/compliance/quickstart-password-compliance-android)
- [Step 7 - Send notifications to noncompliant devices](../device-security/compliance/quickstart-noncompliance-notification)
- [Step 8 - Add and assign an app](../app-management/deployment/quickstart-add-assign)
- [Step 9 - Create and assign an app protection policy](../app-management/protection/quickstart-create-assign-policy)
- [Step 10 - Create and assign custom roles](role-based-access-control/quickstart-custom-role)
- [Step 11 - Create a device configuration profile](../device-configuration/templates/quickstart-email-profile)

## Get started

When you complete the setup, you have a new tenant that's ready to step through the tasks in this series.
